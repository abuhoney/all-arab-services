# منصة الخدمات المتكاملة | All Arab Services

منصة متكاملة لعرض وبيع الخدمات والمنتجات مع نظام نقاط وحجوزات.

## المميزات

- ✅ نظام حجز المنتجات بـ 15% عربون كنقاط
- ✅ نظام إحالات (كل مستخدم جديد = +50 نقطة)
- ✅ ترقية الحسابات (عضو مميز / منشأة مميزة)
- ✅ نظام نقاط ومحفظة رقمية
- ✅ إشعارات فورية
- ✅ كوبونات خصم متنوعة
- ✅ تقييمات ومراجعات
- ✅ لوحة تحكم للمشرف
- ✅ لوحة تحكم للبائع
- ✅ دعم العمل أوفلاين
- ✅ نظام بلاغات ومكافحة غش

## التقنيات المستخدمة

- **Frontend**: HTML5, Tailwind CSS, JavaScript (ES6+)
- **Backend**: Node.js, Express.js
- **Database**: Firebase Firestore
- **Authentication**: Firebase Auth (Anonymous)
- **Storage**: Firebase Storage
- **Hosting**: Render / Firebase Hosting

## متطلبات التشغيل

- Node.js 18+
- حساب Firebase
